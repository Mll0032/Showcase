# 🎲 Game Night Nexus

Welcome to Game Night Nexus –

your ultimate tool for organizing board game nights and managing your growing collection!
Whether you're a casual player or a board game enthusiast, this app has you covered. 🕹️✨

---

## 🌟 Features

- 🧩 **Game Library Management**
  - Add games manually or import your BoardGameGeek (BGG) library.
  - Search for games by name using the BoardGameGeek API.
  - View detailed game info: player count, playtime, cover art, and more.
  - Remove individual games or clear your entire library.

- 🎯 **Game Suggestions**
  - Input the number of players and available time, and get tailored game recommendations from your collection.

- 🔒 **User Authentication**
  - Secure sign-up, log-in, and log-out functionality with JWT-based authentication.

- 📱 **Responsive Design**
  - Optimized for devices of all sizes – mobile, tablet, and desktop.
